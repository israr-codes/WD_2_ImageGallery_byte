# Responsive Image Gallery with Lightbox (Task 2)

A modern, fully responsive Ultra-HD Image Gallery built using HTML5, CSS3 Grid, and Vanilla JavaScript. It features an interactive fullscreen lightbox modal with keyboard navigation support.

## 🚀 Features
* **Fully Responsive Grid:** Automatically adjusts layout across desktop, tablet, and mobile devices (strictly organized with 3 columns per row on desktop).
* **High-Resolution Imagery:** Integrated with optimized Unsplash HD high-resolution image links.
* **Interactive Lightbox:** Click any image to view it in full screen with a background blur effect.
* **Smooth Navigation:** Switch between images inside the lightbox using next/previous buttons or keyboard arrow keys (Escape, ArrowLeft, ArrowRight).

## 🛠️ Tech Stack
* **HTML5** (Semantic markup)
* **CSS3** (CSS Grid, Flexbox, Media Queries, Glassmorphism styling)
* **JavaScript (ES6)** (DOM manipulation and event listeners)
